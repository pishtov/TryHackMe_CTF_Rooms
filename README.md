## 📖 About

This repository contains my personal solutions and notes from completing **TryHackMe CTF rooms**.

The goal is to document the techniques, thought processes, commands, and approaches used while solving different challenges, while also keeping a personal reference for future learning.

The repository is primarily focused on **hands-on learning and practical cybersecurity skills**.

> ⚠️ **Educational use only.**
>
> These write-ups are based on intentionally vulnerable systems and CTF environments. Do not use the techniques described here against systems without explicit authorization.

---

Some write-ups may contain:

* 🚩 Flags
* 💻 Commands
* 🔓 Exploitation steps
* 🔑 Credentials
* 🧠 Hints and solutions

If you're currently working through a room, **try solving it yourself before reading the write-up**.

> **Recommended approach:**
> Attempt → Research → Experiment → Solve → Read the write-up

The write-ups are most useful after you've had a chance to work through the challenge independently.

---

## 🧠 Learning Philosophy

CTFs are not only about finding the flag.

The main purpose of this repository is to build a better understanding of:

**Enumeration → Discovery → Exploitation → Privilege Escalation → Verification**

Each completed room is an opportunity to learn something new, experiment with different tools, and improve problem-solving skills.
